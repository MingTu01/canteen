员工身份二维码 · 扫码验签测试

验证 H5「我的」页生成的员工二维码，扫码后调用 /terminal/verify-qrcode 验签识别员工（仅 X86 取餐终端测试用）。支持摄像头 / 扫码枪(HID) / 网络扫码设备 三种输入。

① 连接配置

获取终端 token：已绑定的终端浏览器按 F12 → Console 执行 JSON.parse(localStorage.getItem('terminal_config_v2')).token； 或调用 POST /api/terminal/bind（管理员账号+密码+食堂安全码）获取。

② 输入方式

点击「开启摄像头」后对准员工二维码
摄像头需在安全上下文（localhost 或 HTTPS）下运行。若在局域网 IP 访问导致摄像头被禁，请改用「扫码枪 HID」或「网络扫码设备」，或浏览器输入 chrome://flags/#unsafely-treat-insecure-origin-as-secure 把本机 IP 加入安全来源。

适用于网络中需要「扫码后上报服务器」的收银/支付类扫码枪（如新大陆、斑马等网络扫码引擎）。 这类设备可在管理页面配置「扫描后发送到 URL」，配置为： http://<本机IP>:8091/scan?data=%s（%s 为扫码内容占位符）。 本页通过 SSE 实时接收扫码结果。需先运行 python network_scan_receiver.py。

③ 验签结果

安全说明
1. 二维码含 HMAC-SHA256 签名（128 bit），服务端常量时间比对，防伪。
2. 验签接口仅终端角色（role=3）可调用，返回含余额的员工信息，其他角色一律 403。
3. 二维码所属门店必须与终端绑定门店一致，跨食堂不可用。
4. 二维码 7 天有效，过期后需在 H5「我的」页重新刷新。
