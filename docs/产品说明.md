# 企业智慧食堂预定餐系统 — 页面DEMO说明文档

## 一、项目概述

本系统为企业内部食堂预定餐解决方案，覆盖4个终端：微信小程序（员工自助）、网页管理端（管理员后台）、X86刷卡订餐终端（现场订餐）、X86取餐终端（打菜确认）。

**核心业务流程**：管理员录入菜品 → 配置每日菜单 → 员工选菜下单 → 就餐时段内取餐。

---

## 二、项目结构

```
meal-system-demo/
├── meal-admin/          # 网页管理端（11个页面）
├── meal-miniapp/        # 微信小程序（4个页面）
├── meal-kiosk-order/    # 刷卡订餐终端（5个页面）
└── meal-kiosk-pickup/   # 取餐终端（3个页面）
```

## 三、各终端页面清单

### 3.1 网页管理端（meal-admin）

| 页面文件 | 功能 | 关键交互 |
|---------|------|---------|
| admin-dashboard.html | 数据总览 | 今日订餐数/金额/菜品统计卡片 |
| admin-dish-mgmt.html | 菜品管理 | 菜品CRUD + 图片上传/预览（无库存字段） |
| admin-menu-mgmt.html | 菜单管理 | 左侧日期选择器 + 右侧按早/中/晚三个餐别显示已配置菜品，"添加"按钮弹出搜索式菜品列表，菜品支持删除(×)和替换 |
| admin-order-mgmt.html | 订单管理 | 搜索框（姓名/工号）+ 状态筛选 + 导出（快捷：本月/上月/当前筛选） |
| admin-employee-mgmt.html | 员工管理 | 员工列表 + 头像显示（管理员上传） |
| admin-dept-mgmt.html | 部门管理 | 部门树形结构 |
| admin-timeslot.html | 就餐时段配置 | 时间段格式（如早餐7:00-10:00），过期未取餐标记"异常" |
| admin-report.html | 报表统计 | 消费/订餐趋势图表 |
| admin-notice-mgmt.html | 通知管理 | 公司通知 + 新品推荐（两个tab） |
| admin-recharge.html | 充值记录 | 管理员为员工充值（无真实支付） |
| admin-settings.html | 系统设置 | 系统管理员账号配置 + 权限管理 |

**管理端侧栏导航（11项）**：数据总览、菜品管理、菜单管理、订单管理、员工管理、部门管理、就餐时段配置、报表统计、通知管理、充值记录、系统设置

### 3.2 微信小程序（meal-miniapp）

| 页面文件 | 功能 | 关键交互 |
|---------|------|---------|
| home.html | 首页 | 滚动通知栏 + 今日新品卡片 + 公司通知列表 |
| order-flow.html | 订餐 | 左侧日期导航（带已选标记圆点）+ 右侧方形卡片网格显示早中晚菜品 + 底部浮动购物车栏（已选菜品摘要+总价+去结算），已选菜品显示蓝色✅标记 |
| order-list.html | 我的订单 | 按日期分组 → 按餐别显示卡片（早餐/午餐/晚餐），每个餐别独立订单可单独取消，取消按钮在卡片右下角 |
| profile.html | 个人中心 | 员工信息 + 头像 + 余额 + 取餐二维码 + 充值记录（无充值按钮，统一管理员后台充值） |

**小程序底部导航（4tab）**：首页、订餐、订单、我的

**购物车模型**：
- 支持多天同时选菜，统一结算
- 购物车显示每天每餐选择的菜品明细
- 提交后按餐别生成独立订单（可单独取消某餐不影响其他）

### 3.3 X86刷卡订餐终端（meal-kiosk-order）

| 页面文件 | 功能 | 关键交互 |
|---------|------|---------|
| kiosk-standby.html | 待机首页 | 时钟 + "请刷员工卡"脉冲动画 |
| kiosk-menu.html | 主菜单 | 订餐 / 查询订单 / 返回三个大按钮 |
| kiosk-dish-select.html | 选菜 | 左侧130px日期导航 + 右侧方形卡片网格（3列）显示所有餐别菜品，底部显示已选数量和去结算按钮，右侧底部"下滑切换下一天"无极下拉提示 |
| kiosk-confirm.html | 确认订单 | 按日期+餐别分组展示所选菜品 + 账户余额 + 合计金额（无取餐时段选择，无取餐码） |
| kiosk-order-list.html | 订单查询 | 左侧日期导航 + 右侧显示当天早中晚订餐状态（已订餐蓝色卡片+取消按钮，未订餐灰色占位，已完成绿色主题） |

**终端流程**：刷员工卡 → 主菜单 → 选菜 → 确认订单

---

### 3.4 X86取餐终端（meal-kiosk-pickup）

| 页面文件 | 功能 | 关键交互 |
|---------|------|---------|
| kiosk-standby.html | 待机首页 | 时钟 + "请刷员工卡取餐"脉冲动画 |
| kiosk-pickup-info.html | 取餐信息 | 员工头像（80px圆形）+ 姓名大字（48px）+ 部门 + 当日菜品大字居中显示（28px，方便打菜人员查看），30秒自动回退倒计时（非阻塞） |
| kiosk-pickup-done.html | 取餐完成 | 打勾动画 + "取餐完成" |

**取餐页面特点**：
- 菜品名称放大居中，打菜人员一眼看到
- 显示员工头像便于确认身份
- 不显示取餐码和窗口号
- 自动回退计时器（30秒），倒计时期间下一个员工刷卡/扫码可立即覆盖显示

## 四、技术规范

### 4.1 设计规范
- 主色：`#0065fd`（蓝色）
- 设计风格：简洁、扁平化、圆角卡片
- 图标库：Lucide Icons
- 布局：响应式（小程序竖屏，管理端/终端横屏）

### 4.2 页面技术栈
- HTML5 + Tailwind CSS v4（CDN）
- Lucide Icons（CDN）
- 纯静态HTML，无后端依赖，浏览器直接打开可查看

### 4.3 业务规则
- **订餐模式**：管理员配菜单 → 员工从预配菜单中选择（非自由点菜）
- **餐别**：早餐、午餐、晚餐（三个时段）
- **时段**：时间段格式（如7:00-10:00），过期未取餐标记"异常"
- **订单粒度**：每个餐别为独立订单，可单独取消
- **支付**：不做真实支付，管理员后台统一充值
- **头像**：由管理员在后台上传，个人中心/取餐页面显示
- **通知**：分为公司通知和新品推荐，由管理员后台发布

## 五、开发实施建议

### 5.1 技术选型建议
| 模块 | 推荐方案 |
|------|---------|
| 后端 | Java/Spring Boot 或 Node.js/NestJS |
| 数据库 | MySQL 或 PostgreSQL |
| 管理端 | Vue3 + Element Plus 或 React + Ant Design |
| 小程序 | uni-app（跨平台）或微信原生 |
| X86终端 | Electron 或 Qt/CEF（全屏Kiosk模式） |
| 刷卡对接 | 串口/USB读卡器SDK |

### 5.2 数据库核心表
- **employees**：员工信息（工号、姓名、部门、头像、余额）
- **departments**：部门
- **dishes**：菜品（名称、图片、价格、分类标签、状态）
- **menus**：菜单（日期、餐别、菜品ID列表）
- **orders**：订单（员工ID、日期、餐别、菜品列表、金额、状态）
- **recharge_records**：充值记录
- **notices**：通知（类型：公司通知/新品）
- **time_slots**：就餐时段配置
- **admin_accounts**：管理员账号

### 5.3 实施顺序
1. 后端服务 + 数据库搭建
2. 管理端开发（数据录入入口）
3. 小程序开发（主要订餐渠道）
4. 刷卡订餐终端开发
5. 取餐终端开发
6. 硬件对接（刷卡器/扫码枪）
7. 联调测试
