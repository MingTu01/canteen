第一步 · 创建食堂

没有食堂，一切无从谈起

登录后进入食堂管理，系统默认无食堂。点击「新建食堂」填写名称、营业信息即可创建。
创建后可进入管理，多食堂场景下通过左上角「切换」在新旧食堂间切换。
第二步 · 创建食堂管理员

给食堂配一个「管家」

在账号管理中为食堂创建管理员：设置账号名、密码（系统自动生成，降低泄露风险）、姓名与角色权限。
1新增账号2绑定食堂3分配角色
第三步 · 就餐时段

定好三餐的「时间窗」

在就餐时段中按餐次（早餐/午餐/晚餐）配置起止时间。时段是后续菜品适用餐次、点单与菜单编排的时间依据。
例早 07:00–09:00例午 11:30–13:30例晚 17:30–19:30
第四步 · 创建部门

先搭好组织架构

在部门管理中按公司组织架构创建部门，支持多级父子结构。员工随后按部门归属，便于统计与订餐汇总。
技术部人力资源部财务部行政部
第五步 · 创建 / 导入员工

把「人」录进系统

在员工管理中可单个添加，也可下载模板批量导入。填写姓名、卡号、手机号并归属部门，设置初始余额与状态。
1添加/导入2绑定卡号3归属部门4设置余额
第六步 · 添加菜品

把「菜」录进系统

在菜品管理中录入菜品：名称、图片、价格、适用餐次、库存与单次限购，并控制上下架状态。
名称/图片价格适用餐次库存/限购
第七步 · 创建菜单

把菜排进每天的餐桌

在菜单管理中按日期编排每日早/中/晚三餐菜品。支持月历快捷切换、按起始日期批量粘贴与批量发布，员工即可在 H5 端订餐。
1选日期2排三餐3批量发布
开通完成

至此，食堂即可正式营业

员工通过 H5 端登录订餐，管理员可在后台继续配置通知、供应商、采购、库存与报表。
通知管理供应商采购库存报表统计
