# 微信公众号功能部署指南

本指南覆盖四项公众号功能：**H5 微信免密登录**、**订阅消息推送（通知/订单）**、**关注后自动回复图文卡片**、**自定义菜单**。

适用前提：已认证的**服务号**（订阅号不支持网页授权和订阅消息）。

---

## 重要变更说明（2025-12-01 起）

微信平台近期有以下重大变更，本指南已全部适配：

| 变更项 | 旧方式 | 新方式 |
|---|---|---|
| 开发接口管理位置 | mp.weixin.qq.com → 设置与开发 → 基本配置 | **微信开发者平台** (developers.weixin.qq.com) → 控制台 |
| 模板消息 | `message/template/send` 接口 | **已于 2021-04-30 下线**，改用订阅消息 `message/subscribe/bizsend` |
| 消息推送(服务器配置) | 支持带端口 | **仅支持 80/443 端口** |
| 网页授权/业务/JS安全域名 | 不支持带端口 | 仍**仅支持 80/443 端口** |

> **端口要求**：微信所有需要回调你服务器的功能（网页授权、消息推送、JS-SDK）均要求 H5 以标准 80/443 端口对外提供 HTTPS 服务。如果你的服务器 443 端口不可用（如未备案被运营商封禁），这些功能无法使用。

---

## 功能可用性矩阵

| 功能 | 是否需要443端口 | 当前代码就绪 | 备注 |
|---|---|---|---|
| H5 微信免密登录 | 是（网页授权域名） | 是 | 需备案后 443 解封 |
| 订阅消息推送 | 否（主动调API） | 是 | 需员工在 H5 端订阅授权 |
| 关注后自动回复 | 是（消息推送URL） | 是 | 需备案后 443 解封 |
| 自定义菜单 | 否（菜单链接可带端口） | 是 | 随时可用 |

> **未备案/无443端口时**：仅「自定义菜单」可直接使用。其余功能需域名备案、443 端口解封后按本指南操作。

## 一、前置条件清单

- [ ] 已认证的**服务号**（订阅号不支持）
- [ ] 域名已备案，服务器 **443 端口**可对外提供 HTTPS 服务
- [ ] H5 以 `https://你的域名`（不带端口）正常访问
- [ ] 后端版本 ≥ 0.0.19（含订阅消息改造）
- [ ] 服务器已安装 Python 3（跑配置脚本用）
- [ ] 公众号管理员微信（扫码授权用）

> 如果 443 端口不可用，仅「自定义菜单」可用，跳到 [第七章](#七自定义菜单) 操作即可。

---

## 二、功能全景与流程

```
员工关注公众号
  ├─ 关注事件 → 后端回调(需服务器配置) → 自动回复图文卡片 → 引导进 H5
  ├─ 自定义菜单 → 点击菜单链接 → 直接进 H5
  │
员工在 H5 内:
  ├─ 微信免密登录(网页授权) → 首次绑手机号+密码 → 之后凭 openid 免密
  ├─ 订阅消息授权(wx-open-subscribe) → 允许后后端可推送通知/订单提醒
  │
后端主动推送(订阅消息):
  ├─ 通知/公告发布 → 推送订阅消息到已订阅员工微信
  └─ 订单创建成功 → 推送订阅消息到下单员工微信
```

## 三、微信开发者平台配置（开发接口）

> 2025-12-01 起，开发接口管理从 mp.weixin.qq.com 迁移至**微信开发者平台**。

### 3.1 登录开发者平台

1. 打开 https://developers.weixin.qq.com/
2. 用公众号管理员微信扫码登录
3. 进入【控制台】

### 3.2 绑定公众号（首次）

1. 点击「新增业务」
2. 填写公众号 AppID
3. 管理员微信扫码授权
4. 绑定成功后，在「已有业务」中进入公众号详情

### 3.3 获取 AppID 和 AppSecret

在公众号详情页找到：
- **AppID**：复制保存（脚本需要）
- **AppSecret**：点「重置」获取（只显示一次，立即复制保存）

### 3.4 配置 API IP 白名单

在公众号详情页找到「API IP白名单」：
- 添加你服务器的**公网 IP**（多个用换行分隔）
- 不配白名单会导致获取 access_token 报 40164 错误

> 注意：这里的 IP 白名单是**开发者 API 用的**，不是 mp.weixin.qq.com 安全中心里的账号安全 IP 白名单。两者不同，别搞混。

## 四、公众号后台配置（mp.weixin.qq.com）

### 4.1 网页授权域名（微信免密登录用）

1. 登录 https://mp.weixin.qq.com
2. 左侧菜单 → 设置与开发 → 功能设置 → **网页授权域名**
3. 填写 H5 域名（**不带 http、不带端口**），如 `canteen.yourdomain.com`
4. 下载校验文件 `MP_verify_xxxx.txt`，上传到 H5 的根目录（nginx 的 html 目录）
5. 点「保存」

> 要求：域名必须以 80/443 端口提供 HTTPS，不支持带端口。未备案无 443 时此项无法通过。

### 4.2 订阅消息模板申请（通知/订单推送用）

1. 左侧菜单 → 广告与服务 → **订阅消息**（原「模板消息」入口）
2. 开通订阅消息功能（需管理员扫码）
3. 在「模板库」中选用或申请模板：
   - **通知模板**：关键词选 标题、内容、时间
   - **订单模板**：关键词选 订单日期、餐次、金额、取餐码、时间
4. 审核通过后，复制**模板 ID**（形如 `f4s8x2k9...`）

> 注意：旧版「模板消息」已于 2021-04-30 下线。现在使用「订阅消息」。订阅消息要求用户主动订阅后才能下发，每次订阅可发一条。

### 4.3 服务器配置（关注后自动回复用）

1. 打开**微信开发者平台** (developers.weixin.qq.com) → 控制台 → 你的公众号
2. 找到「域名与消息推送配置」（原 mp 后台的「服务器配置」）
3. 点「修改配置」，填写：
   - **URL**：`https://你的域名/api/wechat/callback`（**不带端口**，需 443）
   - **Token**：运行 `python3 scripts/wechat_setup.py` 第 3 步会自动生成
   - **EncodingAESKey**：脚本也会自动生成
   - **消息加解密方式**：选「明文模式」
4. 点「提交」→ 微信发 GET 请求校验签名 → 通过即启用

> 要求：URL 必须以 80/443 端口提供 HTTPS，不支持带端口。未备案无 443 时此项无法通过。

### 4.4 准备关注回复封面图（可选）

准备一张 900×500 的图片，上传到公网可访问地址（如 `https://你的域名/banner.png`）。
- 不配则关注后回退纯文本回复
- 配了则回复图文卡片（体验更好）

## 五、服务器配置

### 5.1 运行配置脚本

在项目根目录执行：

```bash
python3 scripts/wechat_setup.py
```

脚本交互流程：

| 步骤 | 内容 | 说明 |
|---|---|---|
| ① 凭证校验 | 输入 AppID + AppSecret | 实时调微信 API 验证是否正确 |
| ② 订阅消息模板 | 输入通知模板 ID + 订单模板 ID | 在第四章 4.2 获取 |
| ③ 服务器配置 Token | 自动生成 Token + EncodingAESKey | 记下来填入开发者平台「域名与消息推送配置」 |
| ④ H5 地址 | 输入 `https://你的域名` | 不带端口（需 443） |
| ⑤ 测试发送 | 可选发送测试订阅消息 | 需提供测试 openid |
| ⑥ 保存重启 | 写入 .env + 重启后端 | 配置生效 |

### 5.2 手动配置（不用脚本）

如果不想用脚本，直接编辑 `.env` 文件：

```bash
nano /opt/canteen/.env
```

填写以下配置项（全部可选，留空不影响系统运行）：

```ini
WECHAT_APP_ID=你的AppID
WECHAT_APP_SECRET=你的AppSecret
WECHAT_TEMPLATE_NOTIFY=通知订阅消息模板ID
WECHAT_TEMPLATE_ORDER=订单订阅消息模板ID
WECHAT_H5_BASE_URL=https://你的域名
WECHAT_TOKEN=服务器配置Token
WECHAT_H5_BANNER_URL=https://你的域名/banner.png
WECHAT_CANTEEN_NAME=企业食堂
```

保存后重启后端：

```bash
cd /opt/canteen
docker compose restart backend
```

### 5.3 配置项说明

| 环境变量 | 用途 | 必填 | 留空影响 |
|---|---|---|---|
| `WECHAT_APP_ID` | 公众号 AppID | 微信功能需要 | 微信功能不可用，手机号登录正常 |
| `WECHAT_APP_SECRET` | 公众号 AppSecret | 微信功能需要 | 同上 |
| `WECHAT_TEMPLATE_NOTIFY` | 通知订阅消息模板 ID | 推送通知需要 | 不推送通知 |
| `WECHAT_TEMPLATE_ORDER` | 订单订阅消息模板 ID | 推送订单提醒需要 | 不推送订单提醒 |
| `WECHAT_H5_BASE_URL` | H5 基础 URL（不带端口） | 推送消息跳转需要 | 消息点击无法跳转 H5 |
| `WECHAT_TOKEN` | 服务器配置 Token | 关注回复需要 | 关注后无自动回复 |
| `WECHAT_H5_BANNER_URL` | 图文卡片封面图 URL | 可选 | 关注后回退纯文本回复 |
| `WECHAT_CANTEEN_NAME` | 食堂名称 | 可选 | 默认"企业食堂" |

> 所有配置项均为可选。不配置任何 `WECHAT_*` 变量，系统完全正常运行（手机号登录、SSE 实时推送、订单管理等核心功能不受影响）。

## 六、微信免密登录与订阅授权

### 6.1 微信免密登录流程

```
员工在微信内打开 H5
  → 后端检测微信浏览器 → 重定向到微信授权页
  → 微信回调带 code → 后端用 code 换 openid
  → openid 已绑定员工 → 直接签发 token，免密进入
  → openid 未绑定 → 弹窗输入手机号+密码 → 绑定 → 进入
  → 下次打开 → 凭 openid 免密进入
```

- 首次需绑手机号+密码（验证身份）
- 之后每次凭 openid 免密登录
- 员工换微信号需重新绑定

### 6.2 订阅消息授权流程

订阅消息要求用户主动订阅后才能下发。员工需在 H5 端通过 `wx-open-subscribe` 开放标签订阅：

```
员工在 H5 内看到订阅按钮（如"订阅订餐通知"）
  → 点击 → 微信弹窗 → 用户点"允许"
  → 后端获得一次发送权限
  → 后端推送通知/订单提醒时消耗一次权限
  → 需再次订阅才能继续推送
```

> 限制：一次性订阅每次只能发一条消息。员工需定期在 H5 端重新订阅。这是微信平台规则，非系统限制。

### 6.3 JS-SDK 配置（订阅授权组件需要）

订阅授权组件 `wx-open-subscribe` 依赖 JS-SDK，需在公众号后台配置 **JS接口安全域名**：

1. mp.weixin.qq.com → 设置与开发 → 功能设置 → **JS接口安全域名**
2. 填写 H5 域名（不带 http、不带端口，需 443）
3. 下载校验文件上传到 H5 根目录

## 七、自定义菜单

自定义菜单不需要 443 端口，菜单链接可带端口。**未备案时也可使用。**

1. mp.weixin.qq.com → 自定义菜单
2. 添加菜单按钮，链接填 H5 地址：
   - 已备案 443：`https://你的域名`
   - 未备案带端口：`https://你的域名:3923`
3. 发布菜单

> 员工关注公众号后，底部菜单可直接点击进入 H5。

## 十、故障排查

### 10.1 access_token 获取失败（errcode=40164）

**原因**：服务器公网 IP 未加入 API IP 白名单

**解决**：微信开发者平台 → 控制台 → 公众号详情 → API IP白名单 → 添加服务器公网 IP

```bash
# 查看服务器公网 IP
curl ifconfig.me
```

### 10.2 access_token 获取失败（errcode=40125）

**原因**：AppSecret 错误

**解决**：微信开发者平台 → 公众号详情 → 重置 AppSecret → 重新填入 .env

### 10.3 服务器配置提交失败（URL 校验不通过）

**原因**：后端未启动 / URL 不可达 / Token 不匹配 / 端口非 443

**排查步骤**：

```bash
# 1. 确认后端在运行
docker compose ps backend

# 2. 确认 .env 中 WECHAT_TOKEN 与开发者平台填的一致
docker compose exec backend env | grep WECHAT_TOKEN

# 3. 手动模拟微信 GET 校验（替换实际值）
curl "https://你的域名/api/wechat/callback?signature=xxx&timestamp=xxx&nonce=xxx&echostr=test"

# 4. 查看后端日志
docker compose logs backend --tail=100 | grep -i wechat
```

### 10.4 关注后没收到回复

**排查**：

```bash
# 确认服务器配置已启用（开发者平台状态为"已启用"）
# 确认后端收到了回调
docker compose logs backend --tail=100 | grep -i "subscribe\|wechat"
```

- 有日志但没回复 → 检查 `WECHAT_H5_BASE_URL` 是否正确
- 无日志 → 服务器配置未启用或 URL 不通

### 10.5 微信登录报 redirect_uri 错误

**原因**：网页授权域名未配置或不匹配

**解决**：mp.weixin.qq.com → 功能设置 → 网页授权域名 → 填写 H5 域名（不带端口，需 443）

### 10.6 订阅消息发送失败（errcode=43101）

**原因**：用户未订阅该模板

**解决**：员工需在 H5 端通过 `wx-open-subscribe` 开放标签订阅后，后端才能推送

### 10.7 订阅消息发送失败（errcode=40037）

**原因**：模板 ID 无效

**解决**：确认 .env 中的 `WECHAT_TEMPLATE_NOTIFY` / `WECHAT_TEMPLATE_ORDER` 与开发者平台的模板 ID 一致

### 10.8 通用排查命令

```bash
# 查看后端版本
curl -s https://你的域名/api/system/version | python3 -m json.tool

# 查看微信配置是否生效
docker compose exec backend env | grep WECHAT

# 查看微信相关日志
docker compose logs backend --tail=200 | grep -i "wechat\|微信\|subscribe\|openid"

# 重启后端
docker compose restart backend
```

## 十一、安全注意事项

1. **AppSecret 等同于密码**，泄露后他人可冒充公众号调用 API。确保 `.env` 在 `.gitignore` 中。
2. **WECHAT_TOKEN** 是回调签名校验密钥，不可泄露，否则可伪造微信回调。
3. 回调接口（POST）有签名校验防伪造，明文模式下 XML 不加密但 subscribe 事件不含敏感信息。
4. 员工 openid 仅存储在后端数据库，不暴露给前端。

## 十二、常用维护操作

### 更新订阅消息模板

1. 开发者平台/公众号后台申请新模板
2. 复制新模板 ID
3. 编辑 `.env` 更新 `WECHAT_TEMPLATE_NOTIFY` / `WECHAT_TEMPLATE_ORDER`
4. `docker compose restart backend`

### 更换 H5 域名

1. 域名解析到新服务器
2. 更新所有域名配置：
   - 网页授权域名（mp 后台）
   - JS接口安全域名（mp 后台）
   - 服务器配置 URL（开发者平台）
   - `.env` 中 `WECHAT_H5_BASE_URL` / `WECHAT_H5_BANNER_URL`
3. `docker compose restart backend`

### 暂时关闭微信功能

编辑 `.env`，清空所有 `WECHAT_*` 变量值，重启后端。系统完全正常运行，仅微信相关功能不可用。
