# 微信公众号功能部署指南

本指南覆盖四项公众号功能的开通：**H5 微信免密登录**、**模板消息推送（通知/订单）**、**关注后自动回复图文卡片**、**自定义菜单**。

适用前提：已认证的**服务号**（订阅号不支持网页授权和模板消息）。

---

## 一、前置条件清单（开工前确认）

| 项 | 要求 | 在哪确认 |
|---|---|---|
| 公众号类型 | 已认证的服务号 | mp.weixin.qq.com → 账号详情 |
| 服务器 | 公网 HTTPS 可访问（H5 域名） | 浏览器外网访问 https://你的域名 |
| 后端版本 | ≥ 0.0.18 | canteen 面板或 /api/system/version |
| Python 3 | 服务器已装 | `python3 --version` |
| 公众号后台权限 | 管理员/开发者权限 | 能进「设置与开发」 |

---

## 二、整体流程（先看全景再动手）

```
第1步 公众号后台取凭证(AppID/AppSecret)
   ↓
第2步 公众号后台配 IP 白名单 + 网页授权域名
   ↓
第3步 服务器跑 wechat_setup.py（自动生成 Token/AESKey）
   ↓
第4步 公众号后台配模板消息（取模板ID，可选）
   ↓
第5步 公众号后台配服务器配置（填回调URL/Token/AESKey，启用）
   ↓
第6步 公众号后台配自定义菜单（你已做）
   ↓
第7步 验证全部功能
```

---

## 三、第1步：获取公众号凭证

1. 登录 [mp.weixin.qq.com](https://mp.weixin.qq.com)
2. 左侧菜单 → **设置与开发** → **基本配置**
3. 记下：
   - **AppID**（开发者ID）
   - **AppSecret**（开发者密码）—— 点"重置"可获取，只显示一次，务必记下

> AppSecret 是敏感信息，等同于密码，不要泄露。

---

## 四、第2步：配置 IP 白名单与网页授权域名

仍在 **设置与开发 → 基本配置**：

### 4.1 IP 白名单
1. 找到「IP白名单」→ 点「修改」
2. 填入**服务器的公网出口 IP**（不是内网IP）
   - 不确定公网IP：在服务器执行 `curl ifconfig.me`
   - 若服务器走代理/ NAT，填出口公网IP
3. 保存

**作用**：后端调微信 API 换 access_token 时，微信校验请求来源IP，不在白名单里会报 40164。

### 4.2 网页授权域名
1. 左侧菜单 → **设置与开发** → **公众号设置** → **功能设置**
2. 找到「网页授权域名」→ 点「设置」
3. 填 H5 访问域名，如 `canteen.yourcompany.com`（不带 http://，不带路径）
4. 微信要求下载一个校验文件（如 `MP_verify_xxxx.txt`），放到 H5 网站根目录
   - 本项目 H5 由 nginx 提供，校验文件放 `h5/dist/` 重新部署，或放 nginx 静态目录
5. 保存

**作用**：H5 微信登录走 snsapi_base 网页授权，授权域名必须在这里登记，否则报「redirect_uri 参数错误」。

---

## 五、第3步：服务器运行配置脚本（核心）

SSH 登录服务器，进入项目根目录（docker-compose.yml 所在目录）：

```bash
cd /opt/canteen   # 你的实际部署目录
```

拉取最新代码（含本次新增的回调功能）：

```bash
git pull
```

运行配置脚本：

```bash
python3 scripts/wechat_setup.py
```

脚本会交互式引导 5 步：

### 步骤① 输入公众号凭证
按提示粘贴 AppID、AppSecret。脚本会**实时调微信 API 校验**凭证是否正确。
- 校验失败常见原因：AppSecret 错误 / 服务器IP不在白名单 / AppSecret 过期
- 校验成功会显示「access_token 获取正常」

### 步骤② 输入模板消息配置（可选）
- 通知/公告模板ID：粘贴公众号后台申请的模板ID（暂无则回车跳过）
- 订单模板ID：同上
- H5 基础URL：填 `https://canteen.yourcompany.com`（末尾不带斜杠）

### 步骤③ 配置关注后自动回复（本次新增）
脚本会**自动生成 Token 和 EncodingAESKey**并显示，**务必记下这两串**：

```
→ 请将此 Token 填到公众号后台服务器配置: a1b2c3d4e5f6...
→ 请将此 EncodingAESKey 填到公众号后台: xyz...
```

然后问：
- 服务器配置 Token：直接回车采用自动生成的值
- 封面图URL：填一张 900×500 公网可访问的图片地址（没有就回车跳过，回退纯文本回复）
- 食堂名称：填你们食堂名，如「XX企业食堂」

### 步骤④ 发送测试模板消息（可选）
用一个已绑定微信的 openid 测试模板推送。首次部署没有绑定用户，直接选「跳过」。

### 步骤⑤ 保存并重启
- 确认保存 → 配置写入 `.env`
- 提示重启，选 `y` 自动执行 `docker compose up -d backend`

---

## 六、第4步：公众号后台配置模板消息（可选，用于推送通知/订单）

1. mp.weixin.qq.com → **功能** → **模板消息**
2. 点「从模板库中添加」，搜索并添加两类模板：

**通知/公告模板**，字段需含：
```
{{title.DATA}}
{{content.DATA}}
{{time.DATA}}
```

**订单模板**，字段需含：
```
{{orderDate.DATA}} {{mealType.DATA}} {{amount.DATA}} {{pickupCode.DATA}} {{time.DATA}}
```

3. 添加后复制**模板ID**（形如 `xxxxxxxxxxxxxxxxxxxxxxxxxx`）
4. 把模板ID填回服务器 `.env`（重跑脚本的第②步，或手动编辑 .env 的 `WECHAT_TEMPLATE_NOTIFY` / `WECHAT_TEMPLATE_ORDER`）
5. 改完 .env 后重启后端：`docker compose up -d backend`

---

## 七、第5步：公众号后台配置服务器配置（启用关注回复，关键）

> 这一步是**关注后自动回复**生效的前提。第3步脚本生成的 Token/AESKey 在这里用。

1. mp.weixin.qq.com → **设置与开发** → **基本配置** → **服务器配置** → 点「修改配置」
2. 填写：

| 字段 | 填什么 |
|---|---|
| URL | `https://canteen.yourcompany.com/api/wechat/callback`（你的H5域名 + `/api/wechat/callback`） |
| Token | 第3步脚本生成的 Token（与 .env 里 WECHAT_TOKEN 必须完全一致） |
| EncodingAESKey | 第3步脚本生成的 EncodingAESKey |
| 消息加解密方式 | 选「**明文模式**」 |

3. 点「提交」

**提交瞬间发生了什么**：微信会立刻向你的 URL 发一个 GET 请求做签名校验，后端 [WechatMessageController](file:///d:/文档/enterprise-canteen/enterprise-canteen/backend/src/main/java/com/example/canteen/controller/WechatMessageController.java) 用 Token+timestamp+nonce 算 SHA1 比对，通过则原样返回 echostr。微信收到正确 echostr → 显示「提交成功」并启用。

4. 启用后，把「服务器配置」的开关打开（如果没自动打开）

---

## 八、第6步：自定义菜单（你已完成）

mp.weixin.qq.com → **功能** → **自定义菜单**。建议底部放一个「去订餐」菜单，链接指向 `https://canteen.yourcompany.com`。

## 十一、出问题怎么排查（故障定位）

### 11.1 脚本校验凭证失败（第①步报错）

```
[错误] 凭证校验失败: errcode=40164, errmsg=invalid ip xxx.xxx.xxx.xxx
```
→ **服务器公网IP不在白名单**。去公众号后台 IP白名单加上报错里的IP。

```
[错误] 凭证校验失败: errcode=40125, errmsg=invalid appsecret
```
→ **AppSecret 错误或已过期**。去公众号后台重置 AppSecret，用新的重跑脚本。

### 11.2 公众号后台提交服务器配置失败

**现象**：点「提交」后提示「URL校验失败」或「Token校验失败」。

按顺序排查：

**(1) 后端是否收到微信的校验请求**
服务器执行：
```bash
docker compose logs backend --tail=100 | grep -i wechat
```
- 看到 `微信服务器配置接入校验通过` → 后端正常，问题在微信那边（罕见）
- 看到 `微信签名校验失败` → Token 不一致：对比公众号后台填的 Token 和 .env 里的 `WECHAT_TOKEN` 是否完全一致
- **完全没看到任何 wechat 日志** → 请求根本没到后端，见 (2)(3)

**(2) URL 是否外网可达**
在本机或手机网络执行：
```bash
curl -i "https://canteen.yourcompany.com/api/wechat/callback?signature=x&timestamp=x&nonce=x&echostr=test"
```
- 返回 200 + 空字符串（或 echostr）→ 网络通
- 返回 404 / 502 / 超时 → 检查 nginx 反代是否把 `/api/` 转发到后端、域名是否解析到服务器

**(3) WECHAT_TOKEN 是否真的传进容器了**
```bash
docker compose exec backend env | grep WECHAT_TOKEN
```
- 空 → .env 没写或 docker-compose.yml 没映射，检查 .env 和 `docker compose up -d backend` 是否重启用新配置
- 有值 → 与公众号后台填的 Token 对比

**(4) 后端版本是否够新**
```bash
curl https://canteen.yourcompany.com/api/system/version
```
version 字段应 ≥ 0.0.18。旧版没有回调接口，会 404。

### 11.3 关注后没收到回复

**(1) 确认服务器配置是「已启用」状态**
mp.weixin.qq.com → 基本配置 → 服务器配置，开关必须是开启的。

**(2) 看后端有没有收到 subscribe 事件**
用一个新微信号关注，立刻看日志：
```bash
docker compose logs backend --tail=50 | grep -i "关注\|subscribe\|wechat"
```
- 看到 `员工关注公众号: openid=xxx` → 收到了，问题在回复（检查 banner URL 是否公网可访问，或看是否有 XML 构造异常）
- 没看到 → 事件没推过来，服务器配置可能没真正启用，或被微信限流（频繁测试关注/取关会触发）

**(3) 封面图URL问题**
未配 `WECHAT_H5_BANNER_URL` 会回退纯文本，属正常。配了但图打不开，微信可能不显示图但仍显示文字。

### 11.4 微信登录失败

**现象**：点微信登录报「redirect_uri 参数错误」
→ 网页授权域名没配或配错。回第2步 4.2 检查。

**现象**：点微信登录报「未配置」
→ `WECHAT_APP_ID` / `WECHAT_APP_SECRET` 没传进容器：
```bash
docker compose exec backend env | grep WECHAT_APP
```

**现象**：绑定页输了手机号密码报错
→ 后端日志看 `/api/employee/wechat/bind` 的报错：
```bash
docker compose logs backend --tail=100 | grep wechat
```

### 11.5 模板消息收不到

**(1) 后端是否尝试发送**
```bash
docker compose logs backend --tail=200 | grep -i "template\|模板"
```

**(2) 常见错误码**
- `40037` 模板ID不对
- `43004` 用户没关注公众号（模板消息只发给已关注用户）
- `40003` openid 不对（用户没绑定，或 openid 不属于此公众号）
- `41028` 模板消息接口权限未开通

**(3) 员工是否绑定了微信**
admin-web → 员工管理，看该员工是否已绑定。没绑定就没有 openid，无法推送。

### 11.6 通用排查命令汇总

```bash
# 看后端最近日志
docker compose logs backend --tail=100

# 只看微信相关
docker compose logs backend --tail=200 | grep -i wechat

# 检查 .env 里的微信配置（AppSecret 会显示，注意保密）
grep WECHAT .env

# 检查配置是否传进容器
docker compose exec backend env | grep WECHAT

# 检查后端版本
curl -s https://你的域名/api/system/version | python3 -m json.tool

# 手动测试回调地址是否可达
curl -i "https://你的域名/api/wechat/callback?signature=x&timestamp=1&nonce=1&echostr=test"

# 重启后端应用新配置
docker compose up -d backend
```

## 十二、安全注意事项

1. **AppSecret 等同于密码**，不要提交到 git、不要发群里。.env 已在 .gitignore。
2. **WECHAT_TOKEN** 是回调签名校验用的，与公众号后台必须一致，不要泄露（泄露后他人可伪造回调请求）。
3. 回调接口虽在白名单（免JWT），但有**签名校验**防伪造（[WechatMessageController](file:///d:/文档/enterprise-canteen/enterprise-canteen/backend/src/main/java/com/example/canteen/controller/WechatMessageController.java) POST 校验 signature）。
4. 明文模式下回调 XML 不加密，subscribe 事件不含敏感信息，风险可控。如需加密，后续可接 wxbizmsgcrypt SDK。

## 十三、常用维护操作

### 修改配置（换 Token / 换封面图 / 加模板）
重跑脚本即可，会保留旧值作为默认：
```bash
python3 scripts/wechat_setup.py
```

### 只改一个值（不跑脚本）
手动编辑 `.env`，改完重启：
```bash
docker compose up -d backend
```

### 关闭关注后自动回复
mp.weixin.qq.com → 服务器配置 → 关闭开关即可（不影响微信登录和模板消息）。或清空 .env 里的 `WECHAT_TOKEN` 重启。

### 查看当前生效配置
```bash
docker compose exec backend env | grep WECHAT
```
